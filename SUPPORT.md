# Support / 使用支持

- **Installation and configuration:** follow the [illustrated guide](https://www.sudotech.ai/katcat-guide.html). Configure missing keys in **Settings → Models**; provider billing and API balances are managed on the provider's platform.
- **Bugs and feature requests:** use the [issue templates](https://github.com/yyshi801207-sketch/Katcat.AI/issues/new/choose). Include your version, OS, installation method, reproduction steps, and expected result. Distinguish clean installations from upgrades retaining data.
- **Development:** start with [CONTRIBUTING.md](CONTRIBUTING.md).
- **Sensitive reports:** use [SECURITY.md](SECURITY.md), not a public bug report.

Remove keys, personal paths, document contents, session text, and account details from logs or screenshots. Do not attach your complete application data directory. Support is community-based with no response-time guarantee.

安装及配置请先查看[图文指南](https://www.sudotech.ai/katcat-guide.html)。密钥可在**设置 → 模型**配置，API 计费和余额由服务商管理。反馈请说明版本、系统、安装方式、复现步骤和预期结果，区分全新安装与保留数据的升级。分享前请移除密钥、个人路径、文档、会话及账号信息，不要上传整个应用数据目录。社区支持不承诺响应时间。
