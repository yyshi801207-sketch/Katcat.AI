# Roadmap / 路线图

These are priorities for discussion, not implemented features or delivery dates. Propose substantial work through [Issues](https://github.com/yyshi801207-sketch/Katcat.AI/issues/new/choose) first.

- Validate Windows installation, upgrade, uninstall, and first use on clean machines.
- Build and validate Katcat on cloud-hosted Mac runners, including branding, signing requirements, and first use.
- Add reproducible office examples with synthetic inputs and reviewable outputs.
- Expand automated product coverage and document reproducible releases.
- Improve accessibility, keyboard interaction, and documentation based on user reports.

以上是讨论中的优先事项，不代表已实现功能或发布日期：验证 Windows 安装生命周期；通过云端 Mac 验证构建、品牌、签名要求和首次使用；补充使用虚构数据的办公示例；扩展自动测试与可复现发行说明；根据反馈改进无障碍、键盘操作和文档。较大改动请先发 Issue 讨论。
