# Security reporting / 安全报告

Katcat.AI is an independent derivative of DeepSeek Harness. Report Katcat-specific issues here. The current product line is 1.0.x; older builds have no guaranteed security support period. Read [SAFETY.md](SAFETY.md) before using agent tools.

If the repository's [Security page](https://github.com/yyshi801207-sketch/Katcat.AI/security) offers **Report a vulnerability**, use it for a private report. Otherwise, open an issue asking for a private channel without sharing exploit details, credentials, or personal data. This document does not enable GitHub's private reporting setting.

Provide the version, OS, affected component, minimal reproduction using synthetic data, impact, and any mitigation. No response time or bug bounty is guaranteed. Coordinate disclosure with the maintainer. Revoke or rotate exposed credentials immediately; deleting a screenshot or Git commit does not invalidate a key.

报告应包含版本、系统、影响组件、使用虚构数据的复现步骤、影响和缓解措施。本项目不承诺响应时限或漏洞奖励，披露请与维护者协调。密钥泄漏后应立即在服务商处撤销或轮换，删除截图或提交记录不能使密钥失效。
