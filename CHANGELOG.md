# Katcat.AI changelog / 更新记录

This file describes Katcat product changes. Harness runtime versions are tracked separately in `package.json` and its compatibility notes in [upgrade guides](docs/upgrade-guide/).

## 1.0.0

- Katcat branding, light and dark interfaces, and a desktop cat companion.
- First-use guidance and DeepSeek API key setup with an option to configure later.
- Katcat Home naming and Windows installer identity updates.
- Office extensions on DeepSeek Harness DSH-0.2.1-rc.2.
- Public source, bilingual introduction, contribution instructions, and GitHub-hosted CI configuration.

This entry does not imply that GitHub binaries or a verified macOS build are available. Downloads are listed on the [product page](https://www.sudotech.ai/katcat.html).
